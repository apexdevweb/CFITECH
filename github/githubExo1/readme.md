 Exo préparatif UAA et github :
Crée une branch pour l'accueil : Page d'accueil (index.html)

Crée une branch pour la connexion : Page de connexion (login.html)

Crée une branch pour le formulaire : Page de formulaire de contact (form.html)

Chaque branch doit avoir au moins 5 commit pour faire des mises à jours dans le projet et à la fin merge dans la main et push la version final sur github (attention les conflis)

Chaque pages doit avoir un minimum de style et agréable à naviguer. (navbar et footer)
